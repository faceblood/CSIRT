ACTUA COMO UN PYTHON SECURITY ENGINEER ESPECIALIZADO EN FORTISIEM, SCAPY Y GENERACION DE LOGS SINTETICOS.

OBJETIVO:
Crear un proyecto CLI-only llamado `fortisiem-simple-log-campaign` con un script unico `fortisiem_log_sender.py` para generar y enviar logs sinteticos realistas a FortiSIEM (default `10.255.9.3:514`) por syslog UDP usando Scapy.

LIMITES:
- No ejecutar ataques reales.
- No escaneo/explotacion.
- Solo simulacion de logs para laboratorio SOC/FortiSIEM.
- Sin frontend, sin FastAPI, sin Docker, sin base de datos.

DEPENDENCIAS:
- Python standard library
- scapy (obligatorio): `pip install scapy`

ESTRUCTURA:

CLI (minimo):
--target
--port
--count
--rate
--campaign phishing|ransomware|apt|bruteforce|vmware-compromise|mixed
--sources fortigate,fortimail,linux,windows,fortiedr,vmware
--loop
--duration
--dry-run
--print-raw
--src-ip-mode random|asset
--send-mode scapy
--step-mode

SEND MODE:
- `scapy` obligatorio (default).
- Implementar `send_syslog_scapy(target, port, message, src_ip=None)`.
- La IP origen del paquete debe coincidir con la IP simulada del log cuando aplique.
- Si falla por permisos/root o dependencia, mostrar error claro.

SYSLOG:
- RFC3164: `<134>MMM DD HH:MM:SS hostname fortisiem-log-sender: message`
- `--dry-run`: no enviar paquetes
- `--print-raw`: imprimir eventos

CONFIG CSV:
1) `config/users_ad.csv`:
   - columnas: `samaccountname,email`
   - generar internamente: SID, domain, user_full
2) `config/vmware_users.csv`:
   - columnas: `username,realm,email,role`
3) `config/assets.csv`:
   - columnas: `ip,hostname,os,source_type`

REPOSITORIO DE LOGS CSV:
- Cargar plantillas desde `log_repository/...`
- Formato comun:
  `id,source,category,event_name,severity,action,weight,template,tags,ttp`
- Si falta repositorio/archivo, usar fallbacks internos.

LOGICA DE CAMPAÑA:
- La narrativa vive en `log_repository/campaigns/<campaña>.csv`
- Formato minimo:
  `step,source,category,event_hint,repeat`
- Ejecutar steps en orden y seleccionar plantilla por source/category/event_hint.

COHERENCIA OBLIGATORIA POR CAMPAÑA:
- misma attacker_ip
- mismo usuario
- mismo endpoint inicial
- mismo C2
- mismo malware
- mismo vCenter/ESXi (si aplica)

`--src-ip-mode`:
- random: attacker_ip externa aleatoria
- asset: IP de assets.csv

CAMPAÑAS:
- phishing: fortimail -> windows -> fortiedr -> fortigate
- ransomware: phishing + powershell + edr ransomware + c2 + vssadmin + vmware impact opcional
- apt: discovery + credential-access + inventory + lateral
- bruteforce: linux/windows/vmware failed logins
- vmware-compromise: vcenter failed/success login + inventory + datastore + snapshot delete + vm power off
- mixed: mezcla ponderada

VMWARE (obligatorio):
- Generar logs estilo vpxd/hostd/vCenter/ESXi:
  - failed login
  - success login
  - inventory enumeration
  - VM/datastore listing
  - SSH enabled ESXi
  - snapshot removed
  - VM powered off

STEP MODE (manual demo):
- `--step-mode` pausa en cada step.
- Mostrar: step actual/total, source, category, event_hint, repeat, src_ip, dst_ip, asset, user.
- Controles:
  - ENTER: ejecutar step
  - s: saltar
  - r: repetir anterior
  - q: salir

EJEMPLOS:
python fortisiem_log_sender.py --campaign ransomware --sources fortigate,windows,fortiedr,vmware --count 100 --rate 5 --src-ip-mode asset

sudo python fortisiem_log_sender.py --campaign vmware-compromise --sources vmware,fortigate --count 50 --rate 3 --src-ip-mode random --step-mode --print-raw
