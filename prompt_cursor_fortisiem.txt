ACTUA COMO UN PYTHON SECURITY ENGINEER ESPECIALIZADO EN FORTISIEM Y GENERACION DE LOGS SINTETICOS.

OBJETIVO:
Crear un unico script Python llamado:

fortisiem_log_sender.py

El script debe generar logs sinteticos realistas y enviarlos por syslog UDP a FortiSIEM usando Scapy.

IP FortiSIEM por defecto:
10.255.9.3

NO ejecutar ataques reales.
SOLO generar y enviar logs sinteticos para laboratorio SOC/FortiSIEM.

============================================================
SCAPY OBLIGATORIO
============================================================

Usar Scapy como metodo obligatorio de envio syslog.

La maquina generadora y FortiSIEM estan en el mismo segmento de red de laboratorio.

La IP origen real del paquete debe coincidir con la IP simulada/reportada en el log.

Implementar:
send_syslog_scapy(target, port, message, src_ip=None)

Ejemplo:
from scapy.all import IP, UDP, Raw, send

packet = IP(src=src_ip, dst=target) / UDP(
    sport=random.randint(1024,65535),
    dport=port
) / Raw(load=message.encode("utf-8"))

send(packet, verbose=False)

Reglas:
- src_ip debe coincidir con la IP usada dentro del log.
- src-ip-mode=random: usar IP aleatoria tambien como IP origen del paquete.
- src-ip-mode=asset: usar IP del asset tambien como IP origen del paquete.
- requiere permisos root/admin.
- mostrar errores claros si Scapy falla.
- mantener coherencia de campaña.

============================================================
STEP MODE
============================================================

Añadir parametro:
--step-mode

Cuando este activo:
- NO avanzar automaticamente entre steps.
- mostrar informacion del step actual.
- esperar ENTER para continuar.
- q = salir
- s = saltar step
- r = repetir step anterior

Mostrar:
- numero de step
- total de steps
- source
- category
- event_hint
- repeat
- src_ip
- dst_ip
- asset
- usuario

Ejemplo output:
[Campaign: vmware-compromise]
[Step 2/9]
Source: vmware
Category: auth
Event: vCenter failed login
Repeat: 3
Src IP: 185.231.88.45
Dst IP: 10.10.60.10
Asset: VCENTER-01
User: administrator@vsphere.local

ENTER = ejecutar
s = saltar
r = repetir
q = salir

Despues mostrar:
Executed step 2/9
Generated events: 3

Si --print-raw:
- imprimir eventos raw.

Si --dry-run:
- no enviar eventos.
